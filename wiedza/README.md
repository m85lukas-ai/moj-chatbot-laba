# Baza wiedzy tutora

Tutor czyta wszystkie pliki `.md` z tego folderu przy każdej wiadomości.
Po każdej lekcji dodaj tu notatki, np. `02_inzynieria_promptow.md`, i odśwież stronę — restart serwera nie jest potrzebny.

Wskazówki:
- Nazwa zaczyna się od numeru lekcji (`02_`, `03_` …), żeby kolejność była czytelna.
- Wklejaj tekst ze slajdów, polecenia warsztatów i treść zadania domowego.
- Nie wklejaj kluczy, haseł ani danych klientów.
- Ten plik (README.md) nie trafia do tutora.
