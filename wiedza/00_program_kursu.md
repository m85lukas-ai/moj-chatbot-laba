## Stały stos technologiczny
- Next.js — interfejs i backend
- Vercel AI SDK + OpenRouter — modele (klucz zapewnia Laba)
- Vercel — deploy i harmonogram (cron)
- Supabase — dane, Auth, pgvector
- Git + asystent kodowania (Codex lub Claude Code) — zmiany i testy
- Node 22+, wersje zapisane w lockfile

## Rytm zajęć
Demo (10 min) → Koncepcja (15) → Warsztat (70) → Test (10) → Pytania (10) → Przerwa (5).
Zasada: najpierw zobacz, potem zbuduj i sprawdź.

## Zasady pracy
1. Zakres Laba — każdy wymagany temat.
2. Własne dane testowe — bez sekretów i danych klientów.
3. Dowód działania — nie samo „gotowe”.
4. Punkt powrotu — test, commit, deploy.
Ty projektujesz, asystent pisze, Ty sprawdzasz: Specyfikacja → Plan → Zmiana → Test (dowód + commit). Jedna mała zmiana na raz.
